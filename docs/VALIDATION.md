# 验证边界

本地候选整理于 2026-10-30，验证平台为 Windows / Python 3.14.7。

## 已通过

- 15 项离线测试：多队账号隔离、各队喊话隔离、聊天上下文、队长位置身份与时效、认证接口、缺失认证时不连接网络、默认禁止启动和建角写库、配置初始化不覆盖、发布扫描器、目录级进程隔离、显式服务器名单、实际 Flask 页面与空队伍接口。
- 在临时目录使用 Flask 测试客户端检查页面和接口，数据库连接被替换为禁止调用；没有连接游戏服务或真实数据库。
- 渲染页面中的一段内联 JavaScript 通过 Node.js `--check` 语法检查；没有执行真实浏览器交互验收。
- 发布文件通过 Python 语法与 JSON 格式检查。首次上传后，GitHub Actions 在 Windows / Python 3.11、3.12、3.13、3.14 上均通过 15 项离线测试及发布文件检查：[首次检查记录](https://github.com/1316596702/tlbb-bot/actions/runs/41012677523)。
- 公开文件扫描未发现已知原环境口令、服务器地址或账号；未纳入抓包、日志、数据库转储、运行角色缓存、EXE、DLL 和 vendor。
- 原开发源码哈希复核未改变；未操作正式服或测试服进程及数据。

尚未验证：本公开副本的游戏登录、实际刷马、地图数据生成、非原协议适配及 Lua 安装。CI 只验证离线代码和文件范围，不连接真实游戏服务。

原有运行环境中的游戏测试不能自动视为本公开副本的验收。
