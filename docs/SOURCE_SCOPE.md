# 本次源码公开范围

发布内容为本项目维护的 Python 功能代码、网页模板、Lua 扩展与新编写的公开协作资料。首次公开建立独立 Git 历史，不导入原开发目录或运行历史。

不发布外部程序、游戏客户端和服务端二进制、普通游戏资源、整份通用道具脚本、私人账号、角色 GUID 名单、抓包、日志、数据库备份或运维恢复材料。

公开副本在整理过程中调整了以下边界：

1. 认证改为本地模块扩展点，不附带会话样本或固定口令。
2. 部署地址改为本地显式配置；数据库口令默认空，角色列表与队伍列表默认空。
3. 数据库维护和服务端部署默认关闭，未适配的关键入口保留明确阻断。
4. 不附带服务端进程内存读取器；相关状态接口需要目标版本重新实现。
5. 进程管理限定本项目目录，避免误接管同机其他实例。
6. Lua 入口要求管理员维护的 GUID 白名单；缺失时拒绝调用。

这些修改仅用于公开副本，不表示现有运行版本已同步修改。其游戏行为需要单独验收。

新增贡献者须在提交前确认自己有权提供相关代码，必要的第三方版权与许可证不能删除。发布前检查不能代替对全部代码权属的独立法律审查。
