# tlbb-bot

**TLBB 智能假人组队刷马系统**

用于研究游戏角色自动化、队伍协作与服务端脚本对接的 Python 项目。通过网页管理多支假人队伍，组织成员集合、跟随、跨地图赶路、寻找夺宝马贼、交互开战和协同攻击。

欢迎通过 Issue、Pull Request 和版本适配报告共同改进。你可以基于代码实现类似功能，也可以把改进贡献回来。

> **当前状态：非商业源码公开预览版。** 行为逻辑源自已有环境中的实现；公开副本移除了私人认证依赖和运行数据，尚未进行新的游戏内验收。它是可研究、可继续开发的代码基础，需要适配目标服务端后才能运行游戏任务。

## 功能与公开版边界

| 能力 | 本目录提供的内容 |
| --- | --- |
| 多队管理 | 网页源码、队伍配置校验、账号占用检查、分服务器配置 |
| 带队刷马 | 集合、目标查找、交互、战斗、切换目标的行为实现 |
| 组队与跟随 | 邀请/申请、协攻、晚入队跟随、掉队恢复逻辑 |
| 地图与移动 | 路径规划、跨地图路线消费、防停步逻辑；需自备合法地图数据与路线 |
| 队长喊话 | 各队独立配置；附近、世界、同城、帮派、门派、队伍、小喇叭的版本相关实现 |
| 服务端扩展 | `server/Jiaren.lua` 集成参考，入口已增加 GUID 白名单校验 |
| 装备维护 | 版本相关算法参考；实际维护入口关闭，需独立验证 |
| 账号认证 | 扩展接口和空实现示例；必须实现真实认证 |

原实现中的消息编号、地图编号、脚本编号、技能编号和物品字段均有版本限制。相同名称不表示二进制格式兼容。

## 能否开发自己的假人系统？

可以。在许可证允许的非商业范围内，你可以 Fork 本项目，搭建本地控制中心，修改网页与行为逻辑，实现自己的队伍任务或新的服务端版本适配，也欢迎把通用改进通过 PR 贡献回来。

本项目提供可继续开发的系统源码，不附带能连接任意服务端的成品配置。账号认证、地图与技能数据、Lua 接口和数据库格式需要你按自己的版本对接；实际游戏效果、稳定性和数据保存由你在自己的测试环境验证。安装成功或网页能打开不代表游戏任务已经通过测试。

## 开始使用

当前控制中心使用 Windows 进程管理接口；先在 Windows 与独立测试服上开发。Python 3.11+ 为开发目标，本地验证环境和结果见 [验证记录](docs/VALIDATION.md)。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe tools/init_local.py
.\.venv\Scripts\python.exe web_console.py
```

浏览器打开 `http://127.0.0.1:8787/`。首次启动没有账号、队伍和凭据；初始化工具只创建不存在的本地文件，不连接服务端。

**查看页面不需要登录游戏。启动假人任务前必须完成 [版本适配](docs/ADAPTING.md)。** 默认不允许数据库写入，公开副本不会自动安装 Lua 或同步远程白名单。控制中心没有面向公网设计的登录认证，不应直接暴露到公网或不可信局域网。
