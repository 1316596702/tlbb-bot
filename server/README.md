# 服务端集成资料

本目录提供项目扩展脚本 `Jiaren.lua`，采用 UTF-8 保存；部署前按目标服要求转码并验证 Lua 版本。

由管理员手动审核安装，仓库没有自动部署或重启服务的脚本。脚本编号 9998496 与函数入口 `Jiaren` 属于原实现约定，先检查目标服注册方式及编号冲突。

入口要求受管 GUID 白名单。默认读取脚本中的 `bot_speaker_allowlist.txt` 路径；文件内容每行一个十进制 GUID，最多 4096 行。按目标安装目录调整路径，名单不在仓库中发布；缺失时拒绝受保护入口。

小喇叭需要对接目标服自己的频道/道具脚本，当前不分发整份普通道具脚本。修理、传送、查怪与补刷接口也需核对目标服 API，不能直接复制后宣称已经兼容。

安装前备份原脚本及注册条目，逐项测试，再记录版本和回退方法。完整流程见 `docs/ADAPTING.md`。
